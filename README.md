# Вариант 18. Импорт данных из старой системы

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Legacy, Adapter, LINQ, async file I/O, DLL

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Разобрать старый формат записей и найти недостатки.
2. Создать современную модель данных.
3. Реализовать интерфейс импортёра.
4. Создать Adapter для старого формата.
5. Асинхронно читать входной файл.
6. Обрабатывать некорректные строки отдельно, не прекращая импорт.
7. Вынести импортёр и модели в DLL.

## Дополнительные задания
8. Добавить параллельную валидацию независимых записей.
9. Сформировать отчёт ошибок через LINQ.
10. Сохранить настройки импорта в реестре.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.

## Запуск

```powershell
dotnet restore
dotnet build
dotnet run
```
